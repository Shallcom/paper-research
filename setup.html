配置研究论文阅读

一次配置后，直接在看板导入 Excel 和记笔记；数据会保存到你的私有仓库。

仓库可见性放入的文件
paper-researchPublic下载包 deploy 文件夹里面的网页文件
paper-research-dataPrivate下载包 private-data/library.json

只把 deploy 里面的内容上传到公开仓库。不要上传整个下载包、Excel、密钥或私人数据。

1. 新建私有数据仓库

  1. 用 shallcom 账号打开 GitHub 新建仓库页面。
  2. 仓库名填写 paper-research-data，选择 Private，勾选 Add a README file，然后创建。
  3. 选择 Add file → Upload files，上传下载包里的 private-data/library.json，提交。文件应直接位于仓库根目录，名字保持 library.json。

这是一个空论文库。首次导入 Excel 会填入论文；已有数据后，不要再上传这个空文件覆盖它。

2. 生成访问密钥

打开 Fine-grained token 创建页面 ↗，检查以下设置：

Token namePaper-Research
Resource ownershallcom
Expiration例如 90 天；到期后重新生成即可，论文不会丢失
Repository accessOnly select repositories，只勾选 paper-research-data
Repository permissionsContents → Read and write
Metadata 保持自动添加的 Read-only，其他权限不用添加

点击 Generate token，复制以 github_pat_ 开头的完整密钥，保存在自己的密码管理器中。不要发给助手、其他人或写进网页文件。只有 Contents 的读取权限时可以查看，但保存会失败。

3. 更新网页

  1. 打开 paper-research 仓库，上传新版 deploy 文件夹里面的内容。根目录直接有 index.html、setup.html、assets 等。
  2. 如果尚未启用 Pages：Settings → Pages → Deploy from a branch → 默认分支（通常 main）→ / (root) → Save。已经启用则保持原设置。
  3. 等待 Pages 部署成功，打开 论文看板，应显示“研究论文阅读”及访问密钥输入框。

从旧公开版升级时，先备份旧看板中的个人记录。删除公开仓库当前的 data/papers.json；若曾上传源码，也检查 source/public/data/papers.json。新版不会再读取公开论文文件。删除当前文件不会清除 Git 历史或他人已保存的旧副本，本次改造不能撤回曾公开的数据。

4. 解锁并首次导入

  1. 输入访问密钥，点击“解锁论文库”。
  2. 若旧看板写过笔记，先导入旧看板导出的完整 Excel，随后导入最新每日 Excel。没有个人记录，可导入下载包 first-import 文件夹里的 6 篇论文表，或更晚的累计表。
  3. 确认合并，等到成功提示，论文即已写入私有仓库，不需要另行上传 JSON。

研究方向固定为 7 类

多模态理解与推理、视频与时序理解、多模态 Benchmark、高效建模与推理、智能体与具身智能、生成模型与世界模型、教育与领域应用。

每篇论文按主贡献归入一个大类。看板根据已有方向和论文标题自动归类，旧论文和新导入论文均适用；原细分方向仍可用于搜索，导出 Excel 使用大类名称。

以后每天这样用

每日 Excel → 拖入看板 → 确认合并。笔记写完点“保存笔记”；收藏和阅读进度修改后立即保存。换电脑打开同一网址、输入密钥即可继续使用。

页面每分钟检查更新，也可以手动刷新。两台设备修改同一笔记发生冲突时，当前草稿会保留，核对后再保存。发生网络错误请先看提示；保存超时可能已提交到 GitHub，先刷新核对，勿直接关闭未保存的草稿。

密钥和论文仅在当前页面内存中使用，本版不会写入浏览器持久存储。刷新、退出或关闭页面后需要重新输入密钥。导出的 Excel 是个人备份，不要上传公开仓库。旧版浏览器缓存不会自动删除，可在备份后自行清理。

遇到问题

  • 找不到仓库或 library.json：检查仓库名、文件是否在根目录，以及 token 是否授权了该仓库。
  • 密钥无效：检查是否完整复制；过期后重新生成 Fine-grained token。
  • 能看不能保存：确认 Contents 是 Read and write，私有仓库没有禁止直接提交的分支规则。
  • 数据仓库不是 Private：程序会停止读写，请检查数据仓库的可见性。
  • 别人能看到什么：网页程序和解锁页公开；论文数据由 GitHub 检查访问权限。持有你的密钥的人也能读写，所以请自行保管。

需要能访问 github.io 和 api.github.com；不使用 ChatGPT，不需购买服务器。完整论文库上限 10 MB，适合当前个人管理规模。此方案不提供额外端到端加密，同一网站来源下的恶意代码或有权限的浏览器扩展仍可能接触当前会话。
